Kikker Forecast

Ad-free weather with Kikker the frog, for Android

Download the app
  1. Tap Download the app. If Chrome asks whether to keep the file, tap Download anyway.
  2. Open the downloaded file. If asked, allow Chrome to install apps, then come back.
  3. Tap Install. If Play Protect warns that the app is unknown, choose Install anyway.
  4. Open Kikker and allow location. Then long-press your home screen, choose Widgets, and add Kikker Forecast.
