# Skyline Weather

Ad-free weather for your phone, built on the National Weather Service API.
Hourly and 7-day forecasts, morning/afternoon/evening summaries, clothing suggestions,
humidity, wind, visibility, air quality, UV, and sunrise/sunset. Uses your device location.

Install on Android: open the site in Chrome, then menu → Install app / Add to Home screen.

Data: api.weather.gov (forecast, observations, alerts); Open-Meteo (air quality, UV, city search).
